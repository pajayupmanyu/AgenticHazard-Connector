# AgenticHazard Connector

Connection details for the AgenticHazard MCP server, which performs probabilistic seismic hazard analysis (PSHA) for Indian sites through natural-language requests to a large language model. The server is hosted by the authors, so no code needs to be downloaded.

This repository holds connection steps only. It does not contain the server code.

## Server link

```
https://agenticoq.tail6aaeec.ts.net/mcp
```

## Connect

**Claude** (available on the free version)

1. Open claude.ai or Claude Desktop, then **Settings → Connectors**.
2. Click **Add custom connector**, paste the link above, and click **Add**.
3. Click **Connect**, then turn the connector on for your chat.

**ChatGPT** (needs a paid plan with custom connectors)

1. Open **Settings**, then the connectors or apps section. Custom connectors may need **Developer mode** turned on.
2. Add a new connector and paste the link above.
3. Click **Connect**, then turn the connector on for your chat.

Menu names change from time to time. If you can't find them, look for "connectors" or "apps" in Settings. Any other MCP-compatible client can connect with the same link.

## Try it

- *What is the 475-year PGA for Delhi?*
- *Compare the uniform hazard spectra of Delhi and Guwahati.*
- *Select ground motions matching the 2475-year spectrum for Chennai.*
